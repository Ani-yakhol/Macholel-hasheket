# מערכת ניטור קול וזיהוי דיבור — גרסה 0.1

תוכנה ל-Windows 10/11 שמאזינה למיקרופון, מזהה דיבור אנושי (להבדיל מרעשי רקע
כמו מאוורר/מזגן), ומפעילה פעולה מותאמת אישית כאשר דיבור בעוצמה מסוימת נמשך
זמן מסוים.

## התקנה (על מחשב Windows)

1. ודאו שמותקן Python 3.10 ומעלה (כולל הוספה ל-PATH בעת ההתקנה).
2. פתחו שורת פקודה בתיקיית הפרויקט והריצו:

   ```
   pip install -r requirements.txt
   ```

3. הפעלה:

   ```
   python main.py
   ```

   התוכנה תיפתח כחלון רגיל, ותמשיך לרוץ ברקע (סמל במגש המערכת) גם אם
   החלון ייסגר. ליציאה מלאה - לחיצה ימנית על סמל המגש ובחירת "יציאה".

## מבנה הקבצים

- `main.py` - נקודת הכניסה: טוען שפה/מראה שמורים לפני בניית כל חלון, ושער כניסה בסיסמה אם הוגדרה.
- `main_window.py` - החלון הראשי: רשימת כללים, מד עוצמה, בחירת מיקרופון, סמל הגדרות.
- `rule.py` - מודל הנתונים של כלל בודד, כולל רשימת הפעולות והמיקומים האפשריים.
- `rule_editor.py` - חלון עריכת/יצירת כלל, כולל כפתור "ניסוי" ועמודים נפרדים לכל סוג פעולה.
- `rule_state.py` - מעקב אחר משך זמן רציף ו-cooldown לכל כלל.
- `audio_engine.py` - האזנה למיקרופון וחישוב "ציון דיבוריות" (VAD).
- `actions.py` - ביצוע הפעולות: התראת טקסט/תמונה, סקריפט, שמע, שינה, כיבוי מסך, כיבוי מחשב.
- `level_meter.py` - ווידג'ט מד עוצמה גרפי.
- `time_field.py` - שדה הזנת זמן בתבנית דקות:שניות עם גלישה אוטומטית.
- `i18n.py` - שכבת תרגום עברית/אנגלית לכל טקסטי הממשק.
- `storage.py` - שמירה/טעינה של כללי הניטור.
- `app_settings.py` - שמירה/טעינה של הגדרות כלליות (סיסמה, שפה, מראה).
- `auth.py` - גיבוב וניהול סיסמה (PBKDF2).
- `login_dialog.py` - חלון התחברות בעת הפעלה (רק אם הוגדרה סיסמה).
- `settings_dialog.py` - חלון הגדרות: לשוניות כללי / סיסמה / אודות.
- `style.py` - מערכת עיצוב מרכזית (בהיר/כהה, RTL/LTR) + תיקון יישור כותרות.
- `version.py` - מספר הגרסה הנוכחי.
- `LICENSE.txt` - רישיון ההפצה (GPLv3).

## תכונות עיקריות

### זיהוי דיבור מול רעש רקע
שילוב של עוצמה (dBFS מעל רצפת רעש נלמדת אוטומטית), קצב חציית אפס, ושטיחות
ספקטרלית - כדי להבחין בין דיבור אנושי (הרמוני) לרעש קבוע כמו מאוורר.

### פעולות נפרדות להתראת טקסט והתראת תמונה
"הצגת הודעת טקסט" ו"הצגת הודעה עם תמונה מוטמעת" הן כעת שתי פעולות נפרדות
ברשימה. שדה בחירת התמונה מוצג רק כשנבחרה פעולת התמונה, ולצדו כפתור
"מחיקת תמונה" למחיקת הנתיב שנבחר. לכל אחת מהן ניתן לקבוע:
- **מיקום הצגה** - רשימה נגללת עם 9 מיקומים על המסך (למעלה/אמצע/למטה ×
  ימין/מרכז/שמאל).
- **אפשרות סגירה ידנית** - תיבת סימון שקובעת האם יוצג כפתור "סגור" על
  ההודעה. ברירת המחדל: לא מוצג (ההודעה נעלמת מעצמה לפי משך הזמן שהוגדר).

### פעולות נוספות: שינה וכיבוי מסך
- **כניסה למצב שינה (Sleep)** - המחשב עצמו נכנס למצב שינה; ניתן להעיר
  אותו בהקשה על מקלדת/עכבר.
- **כיבוי מסך בלבד** - רק המסך כבה (לא כניסה למצב Sleep); ניתן להדליק
  אותו שוב בהקשה על מקלדת/עכבר.

### כפתור "ניסוי" בעריכת כלל
מריץ מיידית את הפעולה הנבחרת לפי הערכים הנוכחיים בטופס. **עבור כיבוי
מחשב, שינה, וכיבוי מסך - הניסוי תמיד מציג תצוגה מקדימה בטוחה בלבד, ולעולם
אינו מבצע את הפעולה האמיתית**, גם אם תיבת האישור (בכיבוי מחשב) לא סומנה.

### שדות זמן בתבנית דקות:שניות
"משך דיבור רציף נדרש" ו"זמן המתנה בין הפעלות" - שדה יחיד בתבנית `00:00`,
הקלדה חופשית או חיצים עם גלישה אוטומטית בין שניות לדקות.

### לשונית "כללי" בהגדרות - שפה ומראה
- **שפת התוכנה** - עברית או אנגלית. שינוי כיוון הממשק (RTL מלא בעברית,
  LTR מלא באנגלית) נכנס לתוקף לאחר הפעלה מחדש של התוכנה (מצוין בממשק).
- **מראה כהה (מצב לילה)** - מוחל מיידית, ללא צורך בהפעלה מחדש.

### הגנת סיסמה (אופציונלי)
גלגל השיניים בפינה השמאלית-עליונה פותח הגדרות, שם ניתן לקבוע/לשנות/למחוק
סיסמה. שינוי או מחיקה דורשים הזנת הסיסמה הנוכחית. הסיסמה נשמרת כגיבוב
מאובטח (PBKDF2-HMAC-SHA256 עם salt).

### תיקון יישור כותרות RTL
לכותרות ה"קופסאות" (למשל "הגדרות מיקרופון", "פעולה לביצוע", "מקרופון פעיל
לניטור כללי") נקבע כעת יישור מפורש לימין ב-RTL (ולשמאל ב-LTR), מאחר ש-Qt
אינו מיישר כותרות QGroupBox אוטומטית לפי כיוון הממשק - ראו הסבר טכני
בתחילת `style.py`.

## הערה לגבי פעולת כיבוי המחשב

פעולה זו דורשת אישור מפורש בממשק (תיבת סימון ייעודית) ומלווה בספירה לאחור
הניתנת לביטול לפני שהכיבוי מתבצע בפועל. מומלץ לבדוק כלל חדש תחילה עם
פעולת הודעת טקסט ועם כפתור הניסוי, לפני מעבר לכיבוי בפועל.

## בניית קובץ הפעלה עצמאי (ללא צורך ב-Python במחשב היעד)

### אפשרות 1 - קובץ EXE בודד (פשוט, אך טעינה איטית יותר)

```
pip install pyinstaller
pyinstaller --noconsole --onefile --name VoiceMonitor main.py
```

### אפשרות 2 - תיקיית הפצה מלאה (מומלץ - אמין יותר עם תלויות בינאריות)

```
pip install pyinstaller
pyinstaller --noconsole --onedir --name VoiceMonitor ^
    --collect-all PyQt6 ^
    --collect-all sounddevice ^
    --collect-all soundfile ^
    --collect-all numpy ^
    --collect-all scipy ^
    main.py
```

(הסימן `^` הוא תו המשך שורה ב-cmd של Windows; ב-PowerShell יש להחליף
בגרש פתוח \` בסוף כל שורה, או לכתוב את כל הפקודה בשורה אחת.)

לאחר ההרצה, כל מה שדרוש להפצה נמצא בתיקיית `dist\VoiceMonitor`. יש לדחוס
את כל התיקייה (לא רק את קובץ ה-EXE) ולהעביר אותה כיחידה אחת למחשב היעד -
היא תרוץ עצמאית ללא Python מותקן.
